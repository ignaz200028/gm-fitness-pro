# GM Fitness Pro PWA per Netlify

## Pubblicazione rapida
1. Estrai lo ZIP.
2. Accedi a Netlify.
3. Apri https://app.netlify.com/drop.
4. Trascina la cartella estratta, non il solo file index.html.
5. Apri l’indirizzo `.netlify.app` assegnato.

## Aggiornamenti
Trascina nuovamente la cartella completa nella sezione Deploys del progetto. Il Service Worker ha una cache versionata e verrà aggiornato.

## Installazione iOS
Apri il sito in Safari, tocca Condividi, quindi Aggiungi alla schermata Home.

## Installazione Android/desktop
Apri il sito in Chrome o Edge e usa Installa app dal menu o dalla barra degli indirizzi.

## Dati
I dati restano nel browser del dispositivo. Esporta regolarmente un backup JSON prima di rimuovere l’app o cancellare i dati del sito.
